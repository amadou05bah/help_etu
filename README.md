Ce projet est un système de question-reponse basé sur l'architecture RAG. Il est entierement local et est concu pour interroger des documents.

## Les étapes du projet 

1. **Extraction du texte et division du texte
2. **La recherche d'information dense ainsi que le re-ranking pour améliorer la préxision 
3. **La synthèse de la réponse final par un LLM local (La bibliotheque ollama)


##Les outils

1. Le language Python
2. PyMuPDF pour l'extraction des fichiers pdf 
3. Les bibliotheques Machine Learning et NLP : SentenceTransformers, Numpy, Pytorch 
4. Le LLM : Ollama
